# Day 03 - Treasure Island 

## Project

Treasure Island is a text-based adventure game where the player makes
different choices to find the hidden treasure.

## Concepts Learned

- Conditional Statements
- if, elif and else
- Logical Operators
- Code Blocks
- Scope
- Nested Conditionals
- String Methods
- User Input

## How It Works

The player makes choices at different stages of the game.

### Example

Choose a direction:

- left
- right

If the player chooses left, they reach a lake and can:

- wait
- swim

If they wait, they reach an island and choose a door:

- red
- yellow
- blue

Choosing the yellow door leads to the treasure.

## Sample Output

You found the treasure. You Win!
