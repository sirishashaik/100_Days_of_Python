# Day 02 - Tip Calculator 

## Concepts Learned

- Data Types
- Numbers
- Mathematical Operations
- Type Conversion
- F-Strings

## Project

A Tip Calculator that calculates the tip, adds it to the total bill,
and splits the final bill equally among multiple people.

## Example

Total Bill: ₹100
Tip: 12%
People: 5

Output:

Each person should pay: ₹22.40
